In short: Cheaptrunk is this website and my main personal project.

It's a tiny virtual private server on the European cloud provider Hetzner. It serves this website through Caddy and runs a handful n8n automations. 

In the following posts I'll describe the architecture behind Cheaptrunk in more detail: the technical choices I made, why I made them, and the real-life problems that I'm trying to solve using automations, AI agents.
